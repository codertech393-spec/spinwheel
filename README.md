# SpinFest 25 — React + TypeScript + Tailwind

An animated gaming-anniversary prize-wheel UI prototype built with Vite, React, TypeScript, Tailwind CSS v4, React Router, Framer Motion, and Lucide icons.

## Run locally
1. Install Node.js 20.19+ (or a current supported Node version).
2. Extract the project.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local Vite URL.

## Build
`npm run build`

## Included pages
- Home / landing
- Spin & Win (animated SVG wheel; client-side demo result)
- Rewards (category filters)
- Winners (fictional showcase)
- How it works
- FAQ (accordion)
- Profile (local nickname storage)
- Contact (client-side validation only)
- Official rules placeholder
- Privacy placeholder
